# Same information, same component

Each kind of information has exactly one component, and wherever it appears, that component shows
it. A new screen picks from this table before drawing anything; a missing part is added to the
library with a story, never drawn once in a screen.

| Information | Component | Where it appears |
|---|---|---|
| State of a task, scan, item or agent | StatusMark | study panel, scan-by-task grid, TaskGraph boxes, Scans, To check, Agents, header line |
| A row's state with its number ("5 to check") | StatusMark, status check | study panel rows, scan rows, Needs you rows, the grid's Status column |
| How many, beside a heading | Count | strip icons, panel heads, page heads, Box heads |
| How far along, one cell per task or scan | Progress | study panel, Home's studies, scan rows |
| One measured value with its unit | Readout | ItemToCheck, the Report's values, Results |
| A short tag, or what the AI sees | Chip | attachments, short tags |
| The workflow and where each task stands | TaskGraph (study, summary, report sizes) | dashboard, Report panel, scan summaries, Workflow page |
| A list of things you can open | Row, or RowLink when it goes somewhere | every list: scans, items, tasks, values, files, agents |
| A table of things with columns | Table | Home's studies, Scans, Results |
| Something waiting for your decision | ItemToCheck | To check (study and scan) |
| An agent's conversation | AgentThread | Agents panel, The AI |
| Where you are | Breadcrumb in the header line | every screen |
| Details about a thing, on demand | Popover | Run details, Study details |
| A choice between a few views | SegmentedControl | By scan / By issue, Status / Values, row density |
| Nothing here yet, loading, or failed | EmptyState, LoadingState, ErrorState | every list and panel |
| A titled block on a page | Box | Home, dashboard |

Text styles follow the same rule: measured values and slice numbers use the mono face; names,
counts and sentences use the text face with tabular figures for numbers.
