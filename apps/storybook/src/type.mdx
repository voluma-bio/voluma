# Type and space

Instrument Sans for words; IBM Plex Mono for numbers, units, ids and coordinates. Body is 14px.

| Utility | Size / line | Use |
|---|---|---|
| `text-xs` | 12 / 16 | metadata, axis labels |
| `text-sm` | 13 / 18 | dense panels, table cells |
| `text-base` | 14 / 20 | body |
| `text-lg` | 16 / 22 | panel and section titles |
| `text-xl` | 20 / 26 | page titles |
| `text-2xl` | 24 / 30 | the study's name on its dashboard |

Spacing is Tailwind's 4px scale (`p-1` = 4px, `p-2` = 8px, `p-3` = 12px, `p-4` = 16px, `p-6` = 24px).
Radii are small: `rounded-sm` 2px, `rounded-md` 3px, `rounded-lg` 4px. Fixed heights: header line
40, panel head 36, row 40 (compact 30), icon strip 64 wide.
